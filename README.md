# weather-app-live-# 🌤️ Interactive Weather App

A fast, responsive web application that provides real-time weather information for any city worldwide using the OpenWeatherMap API and browser local storage.

## ✨ Features

- **Real-Time Weather Data:** Fetches current temperature, weather conditions, humidity, and wind speed.
- **Dynamic Weather Icons:** Visual icons reflecting real-time weather status.
- **Search & Auto-Complete:** Search weather for any global city with instant updates on pressing `Enter` or clicking search.
- **Persistent Storage:** Saves your last searched location to `localStorage` so it loads automatically on your next visit.
- **Robust Error Handling:** Displays clear notification alerts for misspelled or invalid city names.
- **Responsive Interface:** Clean, card-based layout optimized for mobile, tablet, and desktop screens.
